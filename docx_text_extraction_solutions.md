# Решение проблемы с искажением текста при извлечении из DOCX-файлов

## Проблема
При извлечении текста из DOCX-файла с кириллическим содержимым могут возникать искажения символов, например, "злоговыйОператорОгрн" вместо "ЗалоговыйОператорОГРН".

## Возможные причины
1. Некорректная обработка кодировки текста
2. Особенности структуры конкретного DOCX-файла
3. Проблемы с шрифтами или форматированием в документе

## Решения

### 1. Использование альтернативных библиотек

#### Mammoth.js (рекомендуется)
```javascript
const mammoth = require('mammoth');

async function extractTextFromDocx(filePath) {
    try {
        const result = await mammoth.extractRawText({path: filePath});
        const text = result.value;
        return text;
    } catch (error) {
        console.error('Error extracting text from DOCX:', error);
        throw error;
    }
}
```

#### Или использование других библиотек
- `docx` - для более глубокой работы с DOCX-файлами
- `officeparser` - универсальный парсер офисных документов

### 2. Проверка и обработка результата

```javascript
// После извлечения текста можно выполнить дополнительную обработку
function cleanExtractedText(text) {
    // Удалить специальные символы, заменить искаженные символы
    return text
        .replace(/[^\x00-\x7F\u0400-\u04FF\u2000-\u206F\u2E00-\u2E7F\u3000-\u303F]/g, '') // Удалить искаженные символы
        .replace(/\s+/g, ' ') // Заменить множественные пробелы на одиночные
        .trim();
}
```

### 3. Проверка исходного файла

Иногда проблема может быть в исходном DOCX-файле:
- Файл может быть поврежден
- Использовались нестандартные шрифты
- Были вставлены символы из других кодировок

### 4. Полный пример с обработкой ошибок

```javascript
const mammoth = require('mammoth');

async function extractAndCleanText(filePath) {
    try {
        const result = await mammoth.extractRawText({path: filePath});
        let text = result.value;
        
        // Очистка текста от искаженных символов
        text = text.replace(/[^\x00-\x7F\u0400-\u04FF\u2000-\u206F\u2E00-\u2E7F\u3000-\u303F\s]/g, (match) => {
            // Попытка конвертировать потенциально искаженные символы
            return match;
        });
        
        return text.trim();
    } catch (error) {
        console.error('Error extracting text from DOCX:', error);
        throw error;
    }
}
```

## Рекомендации
1. Используйте библиотеку `mammoth` для извлечения текста - она лучше справляется с кодировкой
2. Проверяйте исходные DOCX-файлы на целостность
3. При необходимости добавляйте постобработку текста для очистки от искаженных символов
4. Тестируйте извлечение на различных DOCX-файлах для проверки стабильности решения
